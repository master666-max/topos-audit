# E-B2-4 参照标准定向清单（100 单元）——使用说明

> **先读这段**：这份清单**不是**在让你"标真值"。人不是真值（Devign 4 名专家 × 600 人时，
> 复测正确率仅 24%）。这 100 条的作用是三件：**定向**（打破 Hui–Walter 镜像等价解）、
> **一致性量化**（双盲 → Cohen's κ）、**误差棒**。κ < 0.60 则该轴标称作废——
> 你的不可靠性是要被**测量**的对象，不是要被掩盖的缺陷。
> **判不出来就填 None。** None 是合法答案，比猜一个 0/1 有价值得多。

> 生成：`python -X utf8 EXP/make_b2_e4_sample.py`（约 2 分钟）
> 清单：`EXP/B2-E4-sample.csv`｜目标仓：Python 标准库（N=18198 单元，零下载）

## 抽样分层（PREREG/B2 E-B2-4 规则）

| 层 | 配额 | 含义 | 为什么必须有 |
|---|---|---|---|
| `zero_cover` | 25 | **不在任何池内的单元** | E-X1 教训：盲区里的缺陷不可检出；不入样则标定出的 Se/Sp 只对"池选中区域"有效 |
| `anchor` | 25 | 命中 bandit 锚点（eval/pickle/…） | 语法模式型缺陷的代表层 |
| `confluence` | 20 | Forman 曲率最低三分位（汇合点） | 结构型缺陷的代表层 |
| `random` | 30 | 其余随机 | 无偏基线，防止清单只覆盖"看起来可疑"的单元 |

## 真仓读数（本次生成时的实测）

- 池 4 个，宽度 102 / 102 / 137 / 201
- **零覆盖 97.8%**（17791/18198）——默认演示清单在真仓上覆盖能力极弱，是真实状态不是 bug
- 演化场（churn/age）在标准库上**全 None**（目标仓不是 git 仓 → ADR-A12 如实降级），故演化层本次无法参与分层

## 怎么填（仲裁流程）

`truth` 列留空，其余三列（`defect_type` / `annotator` / `date`）一并填：

| truth | 含义 |
|---|---|
| `1` | 确认有缺陷（写 `defect_type`，如 logic / security / boundary） |
| `0` | 确认无缺陷 |
| `None` | **判不出来就填 None**，不要猜——PU 语义，None ≠ 0 |

**仲裁不是盲标**：先让 LLM 对这 100 个单元独立预标 3 遍（不同提示词），你只裁**分歧样本** + 5% 随机复核。带 `evidence_hint` 列（锚点命中/曲率值/零覆盖标记）辅助判断。预期分歧样本 <40%，即 ~8 小时。

## 假共识哨兵（填完必做）

对照读数：**你 vs LLM 预标的一致率**，不得显著高于**你 vs 真值**的一致率。若前者虚高 → Ising W 假共识成立（你跟着 LLM 走了），预标降级为纯分歧探测器，本批折扣系数作废重标。

## 诚实条款

- 100 单元只用于估“公开集在本域的一致率（折扣系数）”，**不用于直接报系统 Se/Sp**（后者靠 L1 执行正样本 + L5 Hui–Walter）；
- 锚定完成前，任何精度数字只能以“仪器灵敏度”名义出现。
