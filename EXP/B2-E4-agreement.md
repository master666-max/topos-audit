## 2. 主判据读数（决定性）

| 指标 | 值 | 判读 |
|---|---|---|
| **Krippendorff's α（nominal）** | **0.187** | 扣除随机一致后，三裁判几乎无真实一致 |
| α 95% CI（分层 bootstrap, 1000 次） | **[-0.059, 0.453]** | CI 含 0，**上界仍远低于 0.60** |
| **Gwet's AC1** | **0.895** | 表面高度一致 |

**α=0.187 与 AC1=0.895 的反差 = prevalence 悖论的教科书级实证**：
1 率仅 2–11%（边际极端），随机猜也几乎全 0 → α 把"都猜 0"扣掉后所剩无几；
AC1 用均匀 chance 修正故不受此影响。这正是 v1.5 §B3 与 README 假共识哨兵要防的形态——
只不过这次发生在**机器裁判之间**。

**阳性集结构（本对照最硬的一条）**：
- 三裁判**共同认定 = 0 条**；并集 = **15 条**
- 两两阳性交集：A∩B = 0、B∩C = 0、A∩C = 2（#4, #72）
- 阳性标签总数 17 → **退化预案未触发**（阈值 <5），α 可算非 NaN

## 4. 裁决：**L4-control 本轮作废**（不做双阶段补样）

按 v1.5 §B4 的规则字面对照：补样的触发条件是"点估计跨线**且 CI 包含阈值**（方向未定）"。
本轮 **CI 上界 0.453 < 0.60**，方向已定 → **不补样，直接作废**。

- **作废的不是数据，是"把这一层当对照尺"的用法**。三裁判的 100 条判定全部保留为证据，
  不作废、不重标（规则先于判定，事后改判会把对照尺污染成"看过答案"的尺子）。
- 根因诊断（不是笼统的"不可靠"）：
  1. **阳性集不相交**（共同 0 / 并集 15）→ 三裁判对"什么算缺陷"的**判据边界**不同，
     不是随机噪声；
  2. **prevalence 极端**（1 率 2–11%）→ 任何以 0 类主导的一致率都虚高。
- 机器裁判的表现与"人不可靠"完全同构——**这条读数反过来实证了「真值不可得」条款**。

## 5. 对项目的实际后果（不是失败，是路标）

1. **定向锚改由 L1 承担**：三裁判层内 1 率近乎全零，glm5.3 报告 §4.2 的预警成立——
   "序约束的定向锚只能来自 L1 正侧，不能来自模型侧"。

3. **B3 批（解码器）不依赖 L4**，可照常推进。
