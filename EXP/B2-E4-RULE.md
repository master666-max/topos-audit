## None 的四形态（必须在注记里点名是哪一形态）

| 码 | 形态 | 判据 |
|---|---|---|
| `N-CTX` | 跨文件语义缺失 | 工作簿明示「跨文件调用者未扫描」，且该单元的正确性依赖调用方如何用它（例如返回 None 与抛异常的契约由调用方决定） |
| `N-INV` | 依赖未记录不变量 | 正确性取决于类/模块级不变量（锁状态、缓存一致性、初始化顺序），而该不变量不在所示源码内 |
| `N-SHIM` | 壳/转发单元 | 单元体是对另一可调用对象的纯转发或属性搬运，缺陷（若有）在被转发方，本单元无可判内容 |
| `N-VER` | 版本敏感 | 行为依赖 Python 版本/平台分支，所示源码含版本门而工作簿未给靶版本 |

## 判定纪律（防自伤）

1. **不看 `evidence_hint` 定向**：锚点命中（eval/pickle/…）与 Forman 曲率是被检信号，
   不得当作"有缺陷"的证据。判定只读源码与调用关系。命中锚点的单元若无失效机理，照样 `0`。
   —— 这是为了不让对照尺与被检尺同源（否则一致率恒高，`PREREG:62` 判据③的同族错）。
2. **基率不自造**：不因"标准库很成熟"就先验压 `1` 的数，也不因"要证明仪器有用"就抬 `1` 的数。
   每条 `1` 必须有机理句；无机理句的 `1` 一律降 `None`。
3. **私有/下划线单元同权**：`_foo` 不因"内部使用"而免判，也不因"内部使用"而加罪。
4. **None 是合法答案**（`B2-E4-README.md:7`）。宁可 None 不猜 0/1——PU 语义下猜 0 会
   把"未标注"做成"确认干净"，正是 `PREREG:33` 禁止的形态。
5. **每条判定独立落一行 jsonl**，含 `rule` 字段（引用的规则码），使"哪条规则产出哪条读数"可回溯。
