## 1. ① M7 覆盖率门（B7 §1）

### 1.1 契约

```
next 输出 ∈ {NEXT, STOP, BLOCKED-COVERAGE}
zero_cover_rate > θ_cov  ⇒ BLOCKED-COVERAGE（既不是 NEXT 也不是 STOP）
```

| 项 | 规格 | 来源 |
|---|---|---|
| θ_cov | **0.30**，见数据前写死，**只许收紧不许放宽**（T-B7-a） | B7 §1.1 |
| θ_cov 缺失/非法 | **raise**，不给默认值 | B7 §1.1 |
| 输出内容 | 未覆盖单元数 / 已覆盖单元数 / θ_cov / 需要补的池数下界 | B7 §1.1 |
| 退出码 | BLOCKED-COVERAGE ⇒ **3**（区别于 0 / 2） | 本设计新增 |
| 报告必填字段 | `covered_units` / `zero_cover_units` | B7 §1.2 |
| 报告首行 | 覆盖不足时强制印"本次审计未覆盖 X%（N 个单元），以下结论**不适用于**该部分" | B7 §1.2 |

**需要补的池数下界**（本设计定义，此前未定）：
`W = max(min_pool_size, min(max_width, ceil(max_width_pct · n)))`；下界 `= ceil(U / W)`。
理由：每池最多覆盖 W 个单元，覆盖 U 个未覆盖单元至少需要 ceil(U/W) 池。这是**下界**不是目标。

### 1.2 判据映射

| 判据 | 落实方式 |
|---|---|
| D-B7-1 门必须能红 | 在 `EXP/run1_dsh/c`（zcr=0.904）上重放 `next` ⇒ 必须 BLOCKED |
| D-B7-2 门必须能绿 | 构造 zcr ≤ θ_cov 的清单 ⇒ 必须 NEXT/STOP |
| D-B7-3 反证格 | 把 `coverage()` 的 zcr 改恒 0 ⇒ D-B7-1 必须从 BLOCKED 变 NEXT/STOP |
| D-B7-4 契约进自检 | c35 / c36 / c37 |

### 1.3 已登记偏离（如实）

`zero_cover_units` / `covered_units` 在**读旧件**（2026-10-11 前产出的 space.json）时缺失。
规格要求"缺失即 raise"，但那会让所有归档件的报告不可用。
**处置**：新产出必写该字段；读旧件时**现算回填并打印提示**，不 raise。偏离已登记。

## 2. ② A3 调用方向恢复

### 2.1 现状与根因

`layers["call"]` 存 `(min(i,j), max(i,j))` ⇒ 方向在抽取阶段就被丢（`layers.py:288`、langjs 三处）。
后果：跨层错配（岗位三的核心命题）**没有方向维度可用**。

### 2.2 设计（单一表示 + 投影，不做平行层）

- **唯一表示**：`layers["call"]` = `set[(caller, callee)]`（有序）。
- **投影**：`fuse()` 与 `to_adj()` 内部把键归一化为 `(min,max)` ⇒ **几何与所有下游读数不变**（不破基线）。
- **消费**：`layer_fields` 新增 `formula: "out" / "in" / "net"`（出度 / 入度 / 出−入）。
- **修复连带**：`space.summary()` 的 `edges_outside_call` 必须归一化后再比对，否则会误报。

**红线核对**：不是平行实现——方向是**表示**，无向是**投影函数**，二者一个是数据一个是函数。

### 2.3 判据

c41：合成仓上 `fan-out / fan-in` 必须可区分（有向边 (0,1) ⇒ unit0 出度 1、入度 0）；
且 `to_adj` 归一化后边集与改动前**逐字相同**（不破基线）。
