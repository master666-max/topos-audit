## 0. 算法操作化定义（锁定）

**纸面基准声明**：binGroup2 `R/` 经 2026-10-10 grep 核查**无解码器实现**（仅 OTC 设计与期望成本计算；
`DorfmanFunctions.R` 为信息性分层 Dorfman 的成本函数，非解码步骤）。故 DD/SCOMP 按本节操作化定义
独立实现（GPL 不抄码）；与 Aldridge et al. 2014 标准定义的关系在回执中登记。

记号：pos_count(i) = i 所属**阳性**池数；neg_count(i) = i 所属**阴性**池数。
观测 y ∈ {0,1}^P，池清单 rows = [(name, members)]。

| 解码器 | 判阳条件 | 判阴条件 | belief 输出 |
|---|---|---|---|
| **COMP**（=硬排除基线，§6.1 原文） | neg_count(i) == 0 | neg_count(i) ≥ 1 | 判阳=Se，判阴=1−Sp（两档代理分） |
| **DD**（§6.1「阳性池中只出现一次」） | pos_count(i) == 1 且 neg_count(i) == 0 | 其余 | 同上两档代理分 |
| **SCOMP**（§6.1「DD 之后解释残余阳性池」） | D = DD 判阳集；residual = {阳性池 p : p∩D=∅}；迭代把「出现在最多 residual 池的非阴性单元」（并列取 pos_count 大者，再并列取单元序号小者）加入 D，直至 residual 空或无候选；判阳 = D | 其余 | 同上两档代理分 |
| **NB**（逐单元独立后验，decode_mini 同式） | 无二值判定 | — | 连续后验 P ∈ [0,1] |

**条款**：
- **T-B3-a（A8 复申）**：全部解码器只输出 [0,1] belief，禁止 {0,1} 硬值。DD/SCOMP/COMP 的两档分
  （Se / 1−Sp）**仅供排序（AUC）**，不得当校准概率引用；其"二值判定"语义只是两档分数的排序副产品，
  二值化决策属于下游代价函数。
- **T-B3-b（DD 字面口径登记）**：架构书 §6.1 的 DD（singleton 规则）与 Aldridge 2014 标准 DD
  （阳性池并集全员判阳）不同。本项目按**架构书口径**实现（重叠池场景的保守变体）；
  无噪声极限下 singleton-DD 弱于标准 DD，此偏离登记为已知项，回执附对照说明。
- **T-B3-c（NB 先验）**：z_i = logit(π) + Σ_{j∋i} [y_j=1: log(Se/(1−Sp)); y_j=0: log((1−Se)/Sp)]。
  先验 π 为**显式参数**（实验主口径 π = D/n，即已知植入密度；CLI 默认 0.04）。
  先验敏感性 π ∈ {0.02, 0.04, 0.08} 作附加读数（不作主判据）。
- **T-B3-d（图先验自适应，[U]→证伪迭代中）**：v2 曲线（v1.2 修订）——
  泛度 φ_i = w̄_i / N（w̄_i = i 所属池的平均宽，零覆盖单元取场景中位 φ）；
  g(φ) = 1（φ ≤ 0.1）/ 1/(1+(φ/0.1)²)（φ > 0.1）；α_i = (1/λ̂max)·g(φ_i)。
  步数 t=4（敏感性 t∈{1,2,8} 附加）。λ̂max 幂迭代 60 步（decode_mini 搬迁件）。

## 1. E-B3-1 合成图对照（四解码器）

- **空间**：合成图 n=300（两团块 + 桥边，stdlib 随机生成，种子 20261010）；
  池设计：窄池（宽 5–8，随机 BFS 团内采样，约 60 池）。植入 D=8，cluster / scatter 两臂。
- **口径**：Se=0.9，Sp=0.95，200 trials，Se/Sp 噪声同 SynthOracle。
- **判据 D-B3-1a（对照读数存在性）**：四解码器全部产出 AUC 与平衡准确率读数（数字即读数）。
- **判据 D-B3-1b（NB 排序优势）**：cluster 臂 NB 的 AUC ≥ DD 的 AUC（NB 信息利用 ≥ singleton 规则）。
  不咬合 → 登记机理解释，不静默改判据。

## 2. E-B3-2 真仓复现（audit-lab 案例口径）

  经 **topos.Space** 产出融合图（被测空间本体 = topos 引擎底空间产物）。
  第二真仓：stdlib 子集 `…/3.13.12/Lib/xml`（零下载；目录标签 3.13.12 / 解释器自报 3.13.14，登记口径）。
- **口径**：D=8，Se=0.9，Sp=0.95，cluster/scatter 各 200 trials（mini-lab EXP-DEC 案例口径）。
- **判据 D-B3-2（8× 复现，主判据）**：audit-lab cluster 臂 FNR(COMP)/FNR(NB) ≥ 8。
  mini-lab 同空间实测 8.8×（37.3% vs 4.3%）。**不咬合处置**：报实测值 + 机理解释
  （候选：池设计差异 / 覆盖率差异 / 植入落点差异），登记后修订 PREREG 再议，**不许静默放宽**。
- **附读数**：FPR 双臂、stdlib 子集同口径比值（参考，不作判据）。

## 3. E-B3-3 图先验宽度自适应（[U] 证伪测试）

- **场景操作化（v1.2 锁定）**：BFS 团采样池（与 E-B3-1 narrow_pools/wide_pools 同构）——
  宽池场景（单池罩住率 ≥30%，9 池）vs 窄池场景（宽 5–8，40 池）。
  **理由**：topos 空间的池语义 = 耦合团（审计语义单元）；E-B3-1/2 全链同构口径。
- **边界反例登记（v1.2 新发现，随 E-B3-3 一并报告）**：随机稀疏窄池（同宽同池数、随机抽样）
  上图先验增益 ≈ 0（fixed −0.00pp）——证据与耦合团错位时扩散无信号可放大。
  **§6.2 条款的适用前提 = 池-图对齐**；此边界条件随 [F] 升级一并写入架构书修订提案。
- **对照**：NB 无先验（t=0）vs NB+固定 α（1/λ̂max）vs NB+自适应 α（T-B3-d v2 曲线）。
- **判据 U-B3-1（v1.3 修订操作化；原阈值 +5pp 见修订日志③）**：
  - U-B3-1a 宽池场景：自适应图先验 AUC 增益 ≤ **+1pp**（"救泛"应无效）【阈值不动】；
  - U-B3-1b′ 窄池场景（机理天花板判据，比原 +5pp 更严）：
    (i) AUC 增益 ≥ **+4.5pp**；(ii) |增益(自适应) − 增益(固定α)| ≤ **0.05pp**
    （窄池段自适应必须退化为满强度固定 α——设计上限；达不到即曲线有强度损失）；
  - 两条同时成立 → §6.2 条款从 [U] 升 [F]（带边界条件）；任一不成立 → 修正曲线 + v1.x 重跑。
- **护栏 H-B3-1（不伤害）**：任何场景、任何曲线下增益 ≥ −1pp；违反即回退固定 α 并登记。

## 4. 评估与输出纪律（工单禁止条款）

- 全部评估表**同时**含 AUC 与平衡准确率（decode run1 事故条款，§6.3）；accuracy 单指标 = 违规。
- AUC = 秩和 AUC（并列 0.5）；平衡准确率 = (召回 + 特异度)/2，阈值 z>0（NB）/ belief 取两档分界（族）。
- 解码产物 schema `topos-belief/1`：schema、decoder、参数（se/sp/prior/steps/alpha_mode）、
  n_units、belief（unit 级 [0,1]）必填。
