S1 复算载荷（ASCII，落盘后执行，不走 `-c` 内联）：

```python
# EXP/_b6_s1_alpha_inert.py —— α 死旋钮复算器（本批 §0 S1 的凭据生成件）
import json, os, tempfile
from topos.space import Space

LAYERS = ("call", "data", "control", "return", "vardep")

def mf(alpha, path):
    d = {"version": 3, "layers": alpha,
         "fields": [{"name": "forman", "layer": "G", "method": "graph", "params": {}}],
         "slicers": [{"name": "f:low", "field": "forman", "op": "quantile_le", "q": 0.33}],
         "pools": [{"name": "p_f", "expr": "f:low"}],
         "constraints": {"min_pool_size": 1}}
    json.dump(d, open(path, "w", encoding="utf-8"))
    return path

def run(base, tag, alpha):
    p = mf(alpha, os.path.join(tempfile.mkdtemp(prefix="b6s1-"), "mf.json"))
    sp = Space(base, p)
    curv = sp.fields["forman"]
    return {"tag": tag, "edges": len(sp.fused),
            "degsum": sum(len(v) for v in sp.adj.values()),
            "curv_sum": round(sum(v for v in curv.values() if v is not None), 4),
            "pools": [sorted(m) for _n, m in sp.rows],
            "fused_set": sorted(sp.fused)}

if __name__ == "__main__":
    base = os.path.join(os.getcwd(), "topos", "core")
    ones = run(base, "all-1.0", {t: 1.0 for t in LAYERS})
    zeros = run(base, "all-0.0", {t: 0.0 for t in LAYERS})
    skew = run(base, "skew", {"call": 1.0, "data": 100.0, "control": 100.0,
                              "return": 100.0, "vardep": 100.0})
    for r in (ones, zeros, skew):
        print(r["tag"], r["edges"], r["degsum"], r["curv_sum"], r["pools"])
    print("edge sets identical?",
          ones["fused_set"] == zeros["fused_set"] == skew["fused_set"])
```

## 1. 操作化定义（锁定）

### 1.1 范围切分（一次只动一个变量）

| 做 | 不做（登记为 v0.2 议题） |
|---|---|
| 新增**分层场族**（每层各出场）+ **跨层失配场** + 对应切片/池 | 不改 `to_adj`、不引入有向边、不做有向曲率 |
| 把 α **接进一个真实读数**（§1.3 加权合成场），使 c37 从"必红"变"有内容" | 不做层间张量拉普拉斯 / 多层谱分解 |
| 默认清单接线（`axes.json` 增字段，引擎零代码改动） | 不动 sheaf 层（跨层证词拼接留 B6-v0.2） |

**理由**：S1（α 死旋钮）与 S2（方向丢失）是两个独立变量。同批一起动 ⇒ 任何读数变化都无法归因
（对照实验混轴纪律）。本批只动"层是否可分别观测 + α 是否接线"。

### 1.2 分层场族（method 复用现有 `graph`，新增 `formula`）

| 场名 | 定义域 | 值 | 缺失口径 |
|---|---|---|---|
| `deg_call` / `deg_data` / `deg_control` / `deg_return` / `deg_vardep` | 单层邻接 | 该层度数（int） | **0 是合法值不是缺失**（与 `registry.is_missing` 一致；区别于 git 场的 None） |
| `curv_call` / `curv_data` / … | 单层邻接 | 该层 Forman 曲率 `4−deg(u)−deg(v)` 的节点最小值 | 该层无边的单元 = **None**（无定义，禁止填 0，红线 6） |
| `forman_w` | 融合图 | `Σ_t α_t·curv_t(i) / Σ_t α_t` | 见 §1.3 退化处置 |

### 1.3 α 接线（S1 的最小修复）

`forman_w` 是 α 唯一的消费者。**退化处置（锁定）**：`Σ_t α_t == 0` 时
`axis/manifest.py` 校验期 **raise ManifestError**（"layers 权重全零：α 无定义"）——
**不许静默回落等权**（缺失即 bug 文化，对齐 `report/json_out.py:36-38`）。

### 1.4 跨层失配场 `mismatch` [U]

**秩必须在同一单元集合上算**（禁止跨不同分母比较，见 T-B6-a）。对单元 i：

```
r_t(i)   = 单元 i 在层 t 度数序列中的秩（升序，0..N−1，并列取平均秩）
φ_t(i)   = r_t(i) / (N − 1)                     # 归一到 [0,1]
mismatch(i) = max_{t,t'} | φ_t(i) − φ_t'(i) |    # 跨层秩差最大值
```

- **只有 `deg_t` 非缺失单元数 ≥ 6 的层才参与**（n<6 的层秩不稳；同"n<6 符号检验过不了
  0.05"的理由）。参与层集合必须在读数里印出（`layers_used`），不许默认全五层。
- 切片：`mismatch:extreme` = **`op: quantile_ge, q: 0.95`**（`mismatch` 大 = 失配强，故取上尾；
  方向在本件写死，防"分位方向接反"型自伤——接反的症状是切片捞到的是**最一致**的那批，
  而所有下游判据会安静地全绿）。
- 池：`p_xlayer_mismatch`（`expr: "mismatch:extreme"`）。

## 2. 实验与判据

### E-B6-1 合成植入（正反对照，**尺子自检**）

- **空间**：临时目录显式模板仓（非随机生成，植入动作可控可核；沿用 B5-E1 口径）。
  每 trial 12–20 单元。
- **臂**：
  - **正对照臂** 10 trial：植入 1 个"call 层叶子 / data 层枢纽"单元（只被数据流穿过、
    不被任何函数调用），其余单元各层一致。
  - **负对照臂** 10 trial：同构图但**无任何跨层失配**（所有单元各层秩差 ≤ 1 档）。
- **判据**：
  - **D-B6-1a**：正对照臂 `mismatch:extreme` 切片**必须包含植入单元** —— 10/10，逐 trial 打行。
  - **D-B6-1b**：负对照臂植入位命中数 = **0** —— 10/10（封闭自建宇宙，可用"必须为 0"；
    真仓不可，见 E-B6-3）。
  - **D-B6-1c（证伪条款 · 反证格）**：把 `mismatch` 场整体替换为常数场后重跑正对照臂，
    D-B6-1a 必须**从 10/10 掉到 0/10**。若仍命中 ⇒ 该格恒真，判据作废、整跑重做。
- **处置**：**正对照不过 = 尺子坏了**，整跑作废重跑，不许报"靶上没有"（T-B6-d）。

### E-B6-2 α 接线验收（S1 修复的直接判据）

- **靶**：`topos/core`（本仓自身，零下载）。
- **判据**：
  - **D-B6-2a**：α=(1,1,1,1,1) 与 α=(1,0,0,0,0) 下 `forman_w` 场**不相同**（逐单元比，
    报差异单元数，必须 >0）。
  - **D-B6-2b**：α 全 0 → `ManifestError`（不是回落等权、不是静默）。
  - **D-B6-2c（复算 §0 S1）**：修复后重跑 `_b6_s1_alpha_inert.py`，
    "edge sets identical?" 允许仍为 True（边集本就不该受 α 影响），
    但 `curv_sum` 一列**必须随 α 改变**——**读数件改名 `-pre`/`-VOID` 留档，不许原地覆盖**（T-B6-e）。

### E-B6-3 真仓主判据（非合成）

- **靶**：≥2 个真仓 —— ① topos-audit 自身；② dsh-launcher 沙箱（RUN1 同款）；
  ③（可选）Python stdlib 子集。**每个靶独立打行，禁止合并平均后再判**（合并会掩盖单靶失效）。
- **基线（已落盘，不许重算后替换）**：默认清单零覆盖率 —— topos 自身 **0.969**
  （N=355，3 池，`--check` rc=2）；`EXP/run1_dsh/c/space.json` **0.904**（N=250，3 池）。
- **判据**：
  - **D-B6-3a（信号有效性）**：`p_xlayer_mismatch` 池内 anchor 命中率 ≥ **1.5 × 全仓 anchor
    命中率**（阈值 = 外部锚，取自全仓基线而非被检序列自身分位；两者必须同批落盘）。
    对照臂：同宽随机池（`random` 场，种子锁定 **20261009**，同 `axes.json`）。
    随机池命中率必须**低于**失配池，否则本判据不咬合。
  - **D-B6-3b（覆盖增量）**：新场接入默认清单后 `zero_cover_rate` **必须下降**（相对上列基线，
    逐靶报差值）。若不降反升 → 不咬合。
  - **D-B6-3c（准入三读数）**：`topos axis-admit --cand-name p_xlayer_mismatch …` 报
    Δcov / 正相关 ρ / Δlogdet，**三读数合看，不许单读数下结论**（§4.5）。
  - **D-B6-3d（同源登记，诚实条款）**：`mismatch` 与 `forman` 同源于图结构 ⇒
    §4.5 第 2 条"结构正交（信号须来自不同工件类型）"**本批不通过**。
    处置：**如实登记为"同源冗余候选"**，其正相关 ρ 必须报出；ρ≥0.3 时不得单独作为准入依据，
    须与至少一个非图工件类型的场（git 族 / anchor 族）组成组合池再评。
- **证伪条款（触发即回炉，不静默放宽）**：D-B6-3a 在 ≥2 靶上不成立，或 D-B6-3b 升 →
  `mismatch` v0.1 定义判证伪，回 §1.4 换定义（候选：秩差改用层间度数比的 log，
  或改用"层专属邻居占比"），出 v0.2 再测。

## 4. 禁止条款

- **T-B6-a（禁自指尺）**：秩、分位、命中率的分母必须在**同一单元集合**上算；禁止用被检序列
  自身当筛子去噪（那会得到恒等式）。双向差集都要报，不预设白名单。
- **T-B6-b（禁自定阈值）**：判据里的阈值（1.5×）必须是见数据前写死的常数或外部锚；
  清单里的分位参数 `q` 属仪器配置，不算判据阈值，二者不得混用。
- **T-B6-c（禁混轴）**：本批不动底空间（`to_adj`、有向边、层间耦合矩阵）。有向化另开议题。
- **T-B6-d（禁错位拒因）**：正对照不过 = 尺子坏了，作废重跑；不许把自家夹具形状导致的失败
  报成"靶上没有该结构"。
- **T-B6-e（禁覆盖历史读数）**：重跑会原地覆盖已落盘读数件的，先复制成 `-pre`/`-VOID`；
  被覆盖的数不许再引。
- **T-B6-f（禁并表）**：合成植入读数与真仓读数**分表报**，表头标明真值来源
  （"合成真值（作者植入）" / "真仓（无真值，只报命中率与覆盖）"）。
