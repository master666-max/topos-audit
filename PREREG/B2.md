## E-B2-1 Hui–Walter 合成验证（L5 数学兜底的正确性）

- **假设**：两个独立信号源、两个缺陷率不同的群体，Hui–Walter EM 可恢复各源 Se/Sp。
- **方法**：合成两源 × 两群体（真值参数自定：源 A Se=0.80/Sp=0.95，源 B Se=0.90/Sp=0.85；群体缺陷率 π₁=0.05、π₂=0.20；每群体 n=2000）。EM 自编实现（不依赖 crowd-kit，规避实现不可控），bootstrap 95% CI。
- **判据（全部满足=咬合）**：
  1. 四个参数（两源 Se/Sp）的点估计绝对误差 < **0.05**；
  2. 全部真值落在各自 95% bootstrap CI 内；
  3. 违反独立性假设的对照实验（把两源相关性调到 ρ=0.4）下，估计**偏离真值**——确认该方法对假共识敏感（防"无论什么数据都收敛"的假阳性仪器）。
- **期望风险**：小缺陷率群体（π₁=0.05）CI 半宽可能超 0.15 → 如实记录，不掩饰。

## E-B2-2 执行正样本管线（L1）

- **假设**：BugsInPy（Python，~500 真实 bug，带测试）可机器提取函数级标注：bug 版本中**被修复 patch 修改的函数** = 正样本。
- **方法**：抽 ≥3 个项目；`git diff` bug 版→修复版，hunk 映射回函数（复用 `topos.core.units` 的行号定位）；验证 = bug 版触发测试确实 FAIL、修复版 PASS（执行验证，非人工意见）。
- **判据（全部满足=咬合）**：
  1. 产出 **≥100** 个函数级正样本（单元-真值对，含缺陷类型自述）；
  2. 随机抽 5 个 patch 手工核对：函数定位**全对**（0 错位）；
  3. 执行验证通过率 100%（不满足执行验证的样本剔除并计数）。
- **诚实条款**：正样本的函数在修复前"有缺陷"是强断言（测试证明）；**未修改的函数一律标 None（未标注），禁止标 0**。

## E-B2-3 变异注入召回下界（L2）

- **假设**：≥5 类变异算子（常量替换 / 边界偏移 / 条件反转 / 删除调用 / 返回值变换）注入后，"干净版测试过 + 变异版测试挂"构成可计算 mutation score。
- **方法**：在合成仓 + 一个真实小仓（mini-lab 自身）注入；每个变异体跑其单元的既有测试或自动生成的探针测试。
- **判据（全部满足=咬合）**：
  1. mutation score 在工具内可复算（被杀变异体 / 总变异体）；
  2. 干净版**无误杀**（测试不误报）；
  3. 注入命中率报告：至少 3 类算子的变异体可被≥1 个信号源捕获（否则该算子登记盲区）。
- **诚实条款**：score 只报"召回下界"；与真实缺陷的差距（typicality 偏差）写入报告模板。

## E-B2-4 参照标准定向 + 一致性量化（L4，唯一人工层）

> **定性修正（预注册后修订，如实登记）**：本层**不是**在"标真值"——人不是真值。
> 它的作用是三件事：①**定向**：打破 Hui–Walter 的镜像等价解（见 E-B2-1 登记项）；
> ②**一致性量化**：双盲标注 → Cohen's κ，把人的不可靠性变成可观测的量，而不是假装它不存在；
> ③**误差棒**：给折扣系数一个置信区间。
> 若 κ < 0.60，该轴的标称读数作废（同 ARCHITECTURE §4.5 结构正交判据口径）。

- **假设**：100 个分层抽样单元的人工仲裁可给出"SVEN 语义在本域的一致率"读数。
- **方法**：
  1. 抽样：按池分层（锚点命中/churn 分位/零覆盖单元**强制入样**，零覆盖占比 ≥ 其自然比例）；
  2. LLM 预标：同一模型 3 次独立判定（温度 0.7×3，提示词变体），多数票 + 分歧标记；
  3. 人仲裁：只裁分歧样本 + 5% 随机复核（对照 LLM 一致性）；
  4. 对照读数：SVEN 锚定单元上的人机一致率。
- **判据（全部满足=咬合）**：
  1. 100 单元完成仲裁，折扣系数读数的 CI 半宽 **<0.15**；
  2. 5% 随机复核与仲裁结论一致率 ≥80%（仲裁质量自检）；
  3. **假共识检查**：人 vs LLM 预标的一致率**不得显著高于**人 vs 真值的一致率（若人跟着 LLM 走 → Ising W 假共识成立 → 登记，预标降级为纯分歧探测器）。
- **预期工作量**：100 × ≤5 分钟 ≈ 8 小时（分歧样本通常 <40%）。

## E-B2-5 温度缩放（校准层）

- **假设**：解码分数经温度/Platt 缩放后校准误差（ECE）下降。
- **方法**：合成 logits + 已知真率，缩放前后各算 ECE（10 桶）。
- **判据**：缩放后 ECE 较缩放前下降 ≥30%。
