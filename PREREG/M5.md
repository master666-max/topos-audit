## 1. E-M5-1 非 Python 链（D-A 主判据）

- **空间**：express `lib/*.js`（真实仓，非合成）。
- **判据**：
  - **D-M5-1a（单元发现）**：函数级单元 ≥10、require 模块边 **≥6**（v1.1：express lib
    相对 require 地面真值实测 6 条——application→view/utils、express→application/
    request/response、response→utils；v1.0 的 ≥8 是未实测拍的，重蹈 B3 阈值教训；
    6/6 = 抽取器 100% 召回）；
  - **D-M5-1b（链路）**：`space` → `decode` → `next` 三 CLI 在 JS 单元图上全链零退出，
    产出合法 space.json / belief.json / NEXT-or-STOP；
  - **D-M5-1c（sheaf 无虚假证词）**：JS seam 规则 v0.1（R1 require=+1、R4 eval/exec
    非字面量 VETO、R2/R3 留白）下 sheaf 分量全平衡（无 −1 边 ⇒ 不允许出现 ker=0 读数）；
    eval/exec veto 抽查命中与豁免正确（字面量不报）。
- **诚实边界**：JS 后端正则级，**召回必有缺口**（模板串方法、动态 require 不抓）——
  这正是 D-B 存在的理由；本判据只断言"报出的都合法、链路能跑"，不断言"抓全了"。

## 2. E-M5-2 Joern 离线金标校验（D-B 主判据）

- **环境判据**：
  - **D-M5-2a**：`joern --version` 在便携 JRE21 上跑通（JAVA_HOME 按调用注入，系统 Java 不动）。
- **对拍判据**：
  - **D-M5-2b（Python 靶）**：bandit 上 topos call-edge vs Joern pysrc CPG call-edge，
    **precision ≥ 0.8**（topos 报出的边在 Joern 金标中可指认）；**recall 只报数不设门**；
  - **D-M5-2c（JS 靶）**：express lib 同上口径。
- **对拍口径**：边归一化到 (调用方函数, 被调方函数) 无向函数级对；Joern 侧动态调用/继承
  产生的边视为金标超集，不算 topos 误报（金标超集条款）；CALL 类型边取
  `callee` 已解析者（ Joern unresolved 不强求）。
- **判据语义**：topos 抽取器是**被校验对象**——precision 门 = "报出的边不可假"；
  recall 缺口如实报告并归类（正则级已知缺口：动态调用、模板串、隐式调用），喂 v0.2 迭代。
