## 0. 算法操作化定义（锁定）

记号：belief = {i: p_i}（当前后验）；候选池 j ∈ P，成员 m_j，打开代价 c_j（默认 c_j = |m_j|，
开池读数的边际成本代理）；价值 v=1/缺陷发现。**全部池是同一批空间产物（重叠、相关）**。

**价值分布**（belief 导出，工单①）：w_j = Σ_{i∈m_j} 1[i 缺陷] ~ Poisson-Binomial({p_i})，
均值 μ_j = Σ_{i∈m_j} p_i。

**σ 求解（精确式）**：保留值 σ_j 是方程 E[(w_j − σ)⁺] = c_j 的解；Poisson-Binomial 下
数值求解（对 σ 二分，20 步，容差 1e-4）。**σ_j ≥ 0 约束**：c_j > μ_j 时方程无正解 → σ_j = 0
（不值得开）。**代价口径（v1.4 重标定）**：c_j = **c₀ 常数** = 一次池检测成本 / 一个缺陷
价值之比。**默认 c₀ = 0.05**（审计语义：发现一个真缺陷的价值 ≫ 一次池检测成本；
~~v1.1 的 c₀=0.5~~ 意味着"1 个缺陷仅值 2 次检测"，导致单池先验期望 0.17 < 0.5 →
任何未观测池 σ 恒 0 → 自适应永久休眠的假退化，E-B4-1 二跑实证）。
**敏感性 c₀ ∈ {0.05, 0.1, 0.25, 0.5} 全量报告**（c₀ 支配自适应活跃度，是本实验的关键
机理参数）。

**冷启动闭式（[T] Weitzman 1979，架构书 §7.2）**：首轮无观测时，指数族近似下
**σ_j = μ_j − c_j/θ**，θ = 全局发现率参数（= 全体候选池 Σμ / Σc，从先验 belief 自标定；
θ ≤ 0 时全 σ_j = 0 → STOP）。冷启动闭式仅用于 t=0（无任何观测），此后一律精确式。

**停止判据（§7.1 策略，v1.3 修正）**：按 σ 降序开池；每开一池即观测 y → belief 重解码 →
剩余候选池 σ 重算。**STOP ⇔ max(剩余 σ_j) ≤ 0**。
~~v1.2 的"max σ ≤ confirmed（已开池 belief 均值）"~~ 语义错误：Weitzman 的"已开最大 w"
源自开盒**拿走**价值；群验开池**不兑现价值**（缺陷留在单元里，由最终解码兑现，控制层手里
恒 0）——confirmed 类比不成立。σ 本身已扣成本 c₀（E[(w−σ)⁺]=c 的 σ 即净保留值），
故停止纯由"还有没有正净保留值的盒子"驱动：y=1 经重叠池抬升邻居 σ → 继续；
证据不足使剩余 σ 归零 → 早停。预算约束：开池数 ≥ B → 强制 STOP。

**冷启动强制开池（v1.2 修正，E-B4-1 首跑触发）**：t=0 **不做停止判定**（预算已批语义——
控制层的任务是"预算怎么花"而非"要不要搜索"），按 σ 序开首池；σ 全零（低先验场景
c₀>μ_j）时按 μ 降序兜底取首。停止判据自 t≥1 生效。~~v1.1 的 t=0 停止判定~~ 在低缺陷率场景
（μ_j≈0.17 < c₀=0.5）导致 0 池即停、预算作废的假退化，作废。

**下一发选择**：argmax_j σ_j；并列取池宽小者（信息更聚焦），再并列取序号。

## 1. E-B4-1 预算-召回模拟（主判据）

- **空间**：合成图 n=300（B3 同款 gen_graph，种子 20261010）+ 窄池 60（宽 5–8）。
- **植入**：D=8，cluster / scatter 两臂，200 trials。
- **臂**：
  - A（Weitzman 自适应）：belief 驱动 σ 重排序 + 停止判据（精确式，t>0）；
  - B（固定随机顺序基线）：试验前固定随机池序，顺序开池（不用 belief）；
  - C（冷启动静态 σ 序基线）：t=0 闭式 σ 排一次序后固定（区分「σ 排序」与「belief 更新」贡献）。
- **读数**：预算 k=1..8 的召回曲线（已发现缺陷单元数 / D，注意重叠池下开一池可发现多缺陷——
  召回按"经解码判阳且真缺陷"计？**否**——召回按"开过的池覆盖到的真缺陷"计（控制层视角：
  开池动作的信息收益），解码质量不掺入）。
- **判据 D-B4-1（同预算召回更高）**：k=8 时 recall_A ≥ max(recall_B, recall_C)。
- **判据 D-B4-2（同召回预算更省）**：达到 0.9×recall_A(k=8) 所需池数 N_A ≤ N_B 与 N_C
  （达标池数 = 召回曲线首次越过目标线的最小 k）。
- **不咬合处置**：报实测 + 机理分析（σ 信号失效 / 停止过晚 / 重叠池重复发现），修订 PREREG 再议，
  不静默放宽。

## 2. 自检契约（selftest 扩展，锁定编号 c20–c23）

| 编号 | 契约 |
|---|---|
| c20 | σ 值域与单调：c_j ↑ → σ_j ↓；μ_j ↑ → σ_j ↑；c_j ≥ μ_j → σ_j = 0 |
| c21 | 停止方向：belief 全低（<0.01）→ 立即 STOP；belief 高（>0.5 全体）→ 不 STOP |
| c22 | 预算回路终止性：预算 0 → STOP 且无池被开；预算内必终止（guard ≤ B） |
| c23 | CLI next 端到端 smoke：space.json + belief.json → 下一池名或 STOP 输出合法 |
