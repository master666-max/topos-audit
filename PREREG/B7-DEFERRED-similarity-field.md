## 1. 操作化定义（锁定）

### 1.1 骨架化（stdlib only，红线 1/2 合规）

对每个单元的源码 `ast.parse` → 深度优先遍历 → 输出**节点类型串**，其中：

- 标识符（`Name.id` / `arg.arg` / `Attribute.attr`）→ 占位 `ID`；
- 字面量（`Constant.value`）→ 按其 Python 类型占位（`INT` / `STR` / `BYTES` / `FLOAT` / `BOOL` / `NONE`）；
- 其余节点 → 其 `type(node).__name__`；
- **保留** 结构节点顺序与嵌套（用括号或深度前缀），**丢弃** 行号、缩进、注释、docstring。

`SyntaxError` / `ast.parse` 失败 → 该单元骨架 = **None**（缺失，禁止填空串冒充，红线 6）。

### 1.2 相似度

- **shingle**：骨架串的 k-gram 集合，**k=5**（写死；敏感性 k∈{3,5,8} 作附加读数，不进主判据）。
- **相似度** `J(a,b) = |S_a ∩ S_b| / |S_a ∪ S_b|`（精确 Jaccard）。
- **规模门槛**：N ≤ 2000 用精确两两比对；N > 2000 启用 MinHash（`hashlib` + 固定种子置换族，
  128 个哈希），**并在读数里印 `approx=MinHash128` 与其近似误差为盲区**（§5 B4）。
  两档产物**不得并表**（口径不同）。

### 1.3 场与证据的分工（**本批最关键的契约**）

Field 契约是 `unit_id → value | None`（标量），装不下"和谁像"。故：

| 产物 | 内容 | 契约 |
|---|---|---|
| **场** `sim_clone` | `sim_i = max_{j≠i, 同语言, 双方骨架非缺失} J(骨架_i, 骨架_j)` | 标量；无候选对手 → **None**（不是 0） |
| **旁路证据件** `sim_pairs.json` | 每条 `{i, j, J, i_file:line, j_file:line, len_i, len_j, k, approx}` | **缺任一字段即 raise**（不许静默降级；对齐 `json_out.py:36-38` 的"缺失即 bug"） |

**没有对手 id 与 file:line 的相似度读数一律不得进报告**——不可指认即不可复核（§5.1 一次判定
必须能被判断者理解，同理适用于场）。

### 1.4 切片与池

- `sim:clone_top` = `op: quantile_ge, q: 0.95`（相似度最高的 5%；方向写死，防接反——
  接反的症状是捞出**最不像**的那批而下游判据全绿）。
- 池 `p_clone_family` = `expr: "sim:clone_top"`。
- **家族完整性要求**：若 i 入选而它的最大对手 j 未入选（因分位截断），**必须把 j 一并纳入**
  （闭包一步）。理由见 §2 E-B7-1 D-B7-1b：混检要能用**一次判定**覆盖整个同型家族，
  半族入池等于把该机制作废。闭包后池宽仍受 `constraints.max_width` 约束，超限则丢弃 + 告警。

## 2. 实验与判据

### E-B7-1 合成植入克隆（主判据 · 真值=作者植入，表头必须标注）

- **空间**：临时目录显式模板仓（非随机生成，植入可控可核；沿用 B5-E1 口径）。
- **植入**：**K=12 个克隆家族**，每家族 2–4 个成员。成员间做**四种扰动**（每种至少覆盖 3 个家族）：
  ① 全部标识符改名；② 字面量数值/字符串替换；③ 插入无关注释与空行；④ 参数顺序调换 + 中间变量提取。
  其中 **6 个家族植入同一类缺陷**（复用 `calib/mutate.py` 的 `boundary_shift` 算子），6 个家族干净。
- **判据**：
  - **D-B7-1a（家族级召回，全或无）**：`p_clone_family` 必须捞回 **≥10/12 家族的全部成员**，
    逐家族打行（家族号 / 成员数 / 捞回数 / 最大 J / 扰动类型）。**部分捞回算不咬合**
    （半族入池无法用一次判定覆盖同型缺陷，见 §1.4）。
  - **D-B7-1b（机制证明）**：6 个植入缺陷的家族，其成员必须**落在同一个池**内 —— 6/6。
    这是"同型缺陷能被混检利用"的机制格，不是精度格。
  - **D-B7-1c（负向夹具）**：6 个干净家族不得因 `sim_clone` 高而获得任何 **belief 抬升** —— 
    解码后其 belief 与"该场不存在"时的 belief **逐单元相同**（差值必须恒 0）。
    **本夹具不得依赖仪器缺陷**：对照跑法是把 `sim_clone` 从清单里删掉重解码，而不是把场值改成 0。
  - **D-B7-1d（证伪条款 · 反证格）**：把 §1.1 骨架化**关掉**（改用原始 token 串，即保留标识符名），
    重跑扰动 ① 的家族，D-B7-1a 必须**显著下降**（报两档读数）。
    若关掉骨架化仍全捞回 ⇒ 这个格子根本没在测骨架（测的是别的东西），**判据作废、整跑重做**。
- **样本量纪律**：家族数 K=12 < 逐家族下结论所需，故 **D-B7-1a 以合计数判**，
  单家族读数只作诊断行、不单独成立/否证（n<6 不得单独下结论的同款理由）。

### E-B7-2 真仓 precision（非合成 · 可核 · **主判据之二**）

- **靶**：① topos-audit 自身；② dsh-launcher 沙箱（RUN1 同款）；③ 一个第三方 JS 小仓
  （express，M5-E1 已跑通，验 JS 后端不塌）。**逐靶打行，禁止合并平均后判**（合并掩盖单靶失效）。
- **读数**：每靶 top-20 相似对，逐条给全证据（双方 `file:line` + J + 双方骨架长度 + k + approx），
  由 AI 逐条判"是否真克隆"（三值：是/否/判不了 + 形态码），**判定表落 `calib/gold.py` 账本**
  （append-only，重复 unit_id 拒写；`truth=None` 表示判不了，**禁止用 0 冒充"确认不像"**）。
- **判据**：
  - **D-B7-2a**：真克隆比例 **≥ 2/3**（沿用 B5 v0.1 [U] 门槛的误报 ≤1/3 同族口径）。
  - **D-B7-2b**：**不得用"误报必须为 0"**——真仓是公共可写面，"必须为 0"等价于"这段时间
    没人写过重复代码"，是恒假阻塞。改用比例判据 + 噪声余量。
  - **D-B7-2c（诚实条款 · 有界宇宙尺）**：本判据**只能证"有"，不能证"无"**。
    真仓上的**召回不可测**（没有克隆全集），一律登记为盲区（§5 B1），禁止用 precision 读数
    反推"漏得很少"。
- **证伪条款**：D-B7-2a 在 ≥2 靶上不成立 → 骨架化 v0.1 判证伪，回 §1.1 修订
  （候选：保留控制流节点而合并表达式节点 / k 值上调 / 加"长度归一"），出 v0.2 再测。

### E-B7-3 准入与覆盖（接 §4.5 三准则 + §5.3 覆盖法则）

- **判据**：
  - **D-B7-3a（假共识硬门）**：`sim_clone` 与 `anchor` 场的**正相关 ρ 必须报出**；
    **ρ ≥ 0.3 → 不得准入**（这是**硬门**，不是登记项）。理由：风险 R6 + §4.5 第 2 条，
    两栏同读语法长相即同源，同源即一起看走眼，后验会过度自信。
  - **D-B7-3b（三读数合看）**：`topos axis-admit --cand-name p_clone_family …` 报
    Δcov / 正相关 ρ / Δlogdet，**不许单读数下结论**。
  - **D-B7-3c（覆盖增量）**：接入默认清单后 `zero_cover_rate` **必须下降**
    （基线：topos 自身 0.969 / run1_dsh-c 0.904，已落盘，不许重算后替换）。
  - **D-B7-3d（补盲区证明，防"又切了一遍热门"）**：新池覆盖的单元中，
    **此前零覆盖单元的占比必须报出**，且 ≥ 50%。若不达标 ⇒ 说明它只是在重切已有热门单元，
    D-B7-3c 的下降是别处带来的，**归因不成立**。
  - **D-B7-3e（派生格反证）**：把 `sim_clone` 场整体替换为常数场后重跑，
    D-B7-3c/3d 的读数**必须回到基线**。若仍下降 ⇒ 派生格恒真，判据作废。

## 4. 禁止条款

- **T-B7-a（相似只生成池，不抬 belief）**：`sim_clone` **只做覆盖工具**，不得进入解码层的
  证据累加、不得改先验、不得当锚点用。"长得像坏代码"不是罪证。违反即**整批作废**
  （D-B7-1c 是它的守门夹具）。
- **T-B7-b（禁自指阈值）**：判据阈值（2/3、50%、ρ=0.3）必须见数据前写死；清单里的分位 `q`
  属仪器配置（随仓自适应），**不得充当判据阈值**。二者混用即自指。
- **T-B7-c（禁破零依赖）**：不引入第三方嵌入模型 / 向量库 / ANN 库。将来若要上真嵌入，
  走 **Joern 同款"离线算、只读进"** 模式（运行时零 import，产物以 csv/json 进仓，
  许可与接口登记进 `reference/INTERFACE-CHECK.md`），**另开议题，不在本批**。
- **T-B7-d（禁并表）**：合成植入（真值自造）与真仓（无真值）**分表报**，表头标明真值来源；
  精确 Jaccard 与 MinHash 两档**分表报**。
- **T-B7-e（禁覆盖历史读数）**：重跑前先复制成 `-pre`/`-VOID`；被覆盖的数不许再引。
- **T-B7-f（禁错位拒因）**：骨架化失败（SyntaxError）导致的单元缺失，必须在读数里单列
  `parse_fail` 计数，**不得与"没有相似对手"同形**（两者都表现为 None，会指错方向）。

## 6. "全都要"的合用出口判据（B6 + B7 联合验收，非本批单独判据）

本条是 B6/B7 两批**都咬合之后**才跑的联合门，写在这里以免两批各自绿了就宣称拿到"多维+多层"：

- **靶**：≥2 个真仓。挑两类缺陷家族 ——
  **甲类**：只有"看长相"能发现的（植入克隆型错误，B7 的领域）；
  **乙类**：只有"看管线"能发现的（跨层失配接缝，B6 的领域）。
- **三配置对照**：只接分层场 / 只接相似度场 / 两者都接。
- **判据 D-B67-1**：对**每一类**，"两者都接"的召回必须**严格优于**任一单独配置；
  且两场的正相关 ρ < 0.3（否则二者在冗余，只留一套，省下的判据预算转投他处）。
- **判据 D-B67-2**：`zero_cover_rate` 在"两者都接"下必须低于任一单独配置
  （基线 0.969 / 0.904）。
- **不咬合处置**：报实测 + 机理分析（同源冗余 / 样板灌池 / 骨架粒度不匹配），
  修订本件再议，**不静默放宽**。
